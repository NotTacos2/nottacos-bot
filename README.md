# Nottacos-Bot
- This is a simple discord bot that I made, it has moderator commands and minigame commands.

## Features
- Discord bot with slash commands
- Basic Moderator Features (ban, kick, timeout, etc...)
- Minigames features with [m3rcena's remake of weky](https://github.com/M3rcena/m3rcena-weky)

## How do I run this?
```
npm install
node index.js
```
